판정 조건을 말로 적으면:

- 짝 후보: `|ŷ − y| ≤ 0.5·ℓ` **그리고** 가로 겹침 `min(t.x2, p.x2) − max(t.x1, p.x1) > 0`.
- 짝짓기 순서: `|ŷ − y|` **작은 순서**로 1:1 탐욕 (`sorted(...)` 는 오름차순).
- 맞음(`hit`): `|e| ≤ 0.2·ℓ`, `e = ŷ − y`.
- 재현율 = `허용안_짝 / 참값_선`, 정밀도 = `허용안_짝 / 측정_선`, F1 = `2·허용안_짝 / (참값_선 + 측정_선)`.
- 따로 두는 값: `창안_짝` (창 안에서 짝지은 수, 허용 밖도 포함) 과 `창안짝_정밀도 = 창안_짝 / 측정_선`.
- 오차 중앙 = **창 안 짝** 의 `|e|` 중앙값 (허용 안 짝만이 아니다).
- ℓ 은 블록마다: 베이스라인 2개 이상이면 그 차의 중앙값, 아니면 `2 × median(base − xh)`, 아니면 판 중앙값.
- 측정 선에서 빼는 것 (`line_score:485–488`): 측정 블록이 제외 사유 블록 안에 `inside ≥ 0.5` 이면 뺀다(`ex_f`),
  그 다음 글줄 판독 불가 블록 안에 `inside ≥ 0.5` 이면 뺀다(`ex_i`). 남은 블록(`live`)의 선만 `측정_선` 에 든다.
- ③(두 라벨러 일치 항목) 은 정밀 분모를 더 줄인다 — `정밀분모에서_뺀_측정선` (`:996`), 짝 후보 조건도 두 라벨러 값 모두에 대해 본다 (사전등록 수정 1 «③ 의 채점 정의 · 선»).

판정 조건을 말로 적으면:

- 짝짓기 전에 **측정 묶음을 뺀다**: 제외 사유 블록 `x` 에 대해 `inside(묶음, x) ≥ 0.5` 이면 뺀다 (`제외로_뺀_묶음`).
- 짝 후보: `IoU ≥ t` (주 0.5, 민감도 0.3), **IoU 큰 순서**로 1:1 탐욕.
- 재현 = `짝 / 참조`, 정밀 = `짝 / 묶음`(뺀 뒤 수), F1 = `2·짝 / (참조 + 묶음)`.
- 판마다 센 값을 `Counter` 로 합산한 뒤 F1 을 낸다 (판별 F1 의 평균이 아니다).
- 과병합: 한 묶음이 **서로 다른 참조 둘 이상**을 각각 `held ≥ 0.5` (참조 넓이 기준) 로 덮은 경우의 **묶음 수**.
- 과분할: **짝 못 지은** 묶음 가운데 **어떤 한 참조** 안에 `inside ≥ 0.5` (묶음 넓이 기준) 로 든 **묶음 수**.
- 헛것: 어느 참조와도 겹치지 않는 묶음 수.
- ③ 은 두 라벨러 상자에 대해 `min(IoU)` · `min(held)` · `min(inside)` 를 쓰고 제외 범위도 더 넓다 (`block_counts_agreed`).

## 2. 1절의 (c) 와 `docs/brockmann_stage2_result.json` 이 같은가

| 항목 | 1절 (c) · 합의 | `brockmann_stage2_result.json` 합의 베이스라인 | 같은가 |
|---|---|---|---|
| 참값 선 | 921 | 921 | 같다 |
| 측정 선 | 903 | 901 | **다르다** |
| 창 안 짝 | 829 | 829 | 같다 |
| 허용 안 짝 | 823 | 823 | 같다 |
| 재현율 | 0.8936 | 0.8936 | 같다 |
| 정밀도 | 0.9114 | 0.9134 | **다르다** |
| 창안짝 정밀도 | 0.9181 | 0.9201 | **다르다** |
| 오차 절대 중앙 | 0.0 | 0.0 | 같다 |

**원인.** 짝과 맞음은 같다 (창 안 짝 829 · 허용 안 짝 823). 다른 것은 `측정_선` 분모뿐이다 — 903 대 901.
두 경로가 측정 선을 거르는 단위가 다르다:

- `brockmann_stage2_score.line_score:485–488` — **측정 블록 단위**로 뺀다. 블록이 제외 사유 블록 안에
  `inside ≥ 0.5` 이면 그 블록의 선 전부를 빼고(`ex_f`), 글줄 판독 불가 블록에 대해 한 번 더 뺀다(`ex_i`).
- `eval/explore_vlm_baseline.keep:156–157` — **선 하나 단위**로 뺀다. 선의 가로 중점이 제외 영역의
  가로 범위 안이고 y 가 그 영역 안일 때만 뺀다.

그래서 같은 캐시 · 같은 참조인데도 측정 선이 2개 더 남아 정밀도가 0.9114 대 0.9134 로 갈린다.
재현율은 분모가 참값 선(921)이라 완전히 같다.

### 2.1 짝지은 줄 수와 미검출 수

**맞지 않는다 — 다른 함수의 수다.** 미검출 93 은 `eval/explore_split_lines.missed_causes:89–129` 가 낸 값이고,
1절·stage2 의 선 채점(`line_score` · `_direct`)과 세 가지가 다르다:

1. **측정 선을 거르지 않는다.** `missed_causes` 는 캐시의 모든 블록 베이스라인을 후보로 쓴다
   (제외 사유 · 판독 불가 블록을 빼지 않는다, `:106`).
2. **행간 ℓ 규칙이 다르다.** 블록 안 베이스라인이 1개면 `2 × (base − xh)` 를 쓰고 그것도 없으면 `2 × 10.0` 을
   쓴다 (`:99–102`). `block_L` 의 3번째 규칙(판 중앙값)이 없다.
3. 그래서 같은 캐시로 돌리면 짝이 828 이고 (921 − 93), `line_score` 의 허용 안 짝 823 보다 5 많다.

즉 «미검출 93» 과 «놓친 라벨 92/98» 은 **같은 수를 다르게 센 것이 아니라 정의가 다른 수**다.
논문에 둘을 나란히 쓰면 서로 맞지 않는다.

## 4. 논문에 적힌 지표 정의와 코드가 다른 곳

논문 문단(아래 «논문» 열)을 0절의 코드와 한 줄씩 맞춘 목록이다. **코드를 고치지 않았고 논문 문구도
고치지 않았다** — 다른 자리만 적는다.

### 4.1 선 채점

| # | 논문 | 코드 | 무엇이 다른가 |
|---|---|---|---|
| L1 | «두 선의 차가 0.5ℓ 이내인 쌍을 … 대응» | `_direct:468–469` 는 `|ŷ−y| ≤ 0.5·ℓ` **그리고** `min(t.x2, p.x2) − max(t.x1, p.x1) > 0` | **가로 겹침 조건이 빠졌다.** 코드는 가로로 전혀 겹치지 않는 선끼리는 짝짓지 않는다 |
| L2 | «해당 블록의 행간을 ℓ» | `block_L:202–212` — 베이스라인 2개 이상이면 그 차의 중앙값, 1개면 `2 × median(base − xh)`, 그것도 없으면 **판 전체 중앙값** | ℓ 의 세 갈래 규칙이 빠졌다. 특히 한 줄 블록과 x높이선 없는 블록에서 값이 달라진다 |
| L3 | «정밀도는 맞은 수를 \|Ŷ\|로 나눈 값» | `_stats:694` 의 분모 `n_m` 은 `line_score:485–488` 에서 **측정 블록을 빼고 남은**(`live`) 블록의 선 수 | 분모에서 빼는 규칙이 빠졌다 — 제외 사유 블록 안 `inside ≥ 0.5` 인 측정 블록(`ex_f`), 그 다음 글줄 판독 불가 블록 안 `inside ≥ 0.5` 인 블록(`ex_i`) |
| L4 | (없음) | `_stats:694` 는 `창안짝_정밀도 = 창안_짝 / 측정_선` 을 따로 낸다 | 코드에는 정밀도가 **둘**이다. 논문은 하나만 적어, 결과 파일의 `창안짝_정밀도` 와 혼동될 수 있다 |
| L5 | «오차 중앙은 \|e\|의 중앙값» | `_stats:695` 는 **창 안 짝 전부**(허용 밖 포함)의 `|e|` 중앙값 | 어느 집합의 중앙값인지가 빠졌다. «맞은 쌍의 중앙값» 으로 읽으면 다른 수가 된다 |
| L6 | (없음) | ③(두 라벨러 일치 항목) 은 짝 후보를 두 라벨러 값 **모두** 에 대해 `≤ 0.5·ℓ` 로 보고, 짝짓기 비용이 «두 차의 절댓값 가운데 큰 쪽», 허용도 두 차 모두 `≤ 0.2·ℓ`, 정밀 분모를 더 줄인다 (`정밀분모에서_뺀_측정선`, `:996`) | 논문 정의는 참조가 하나인 경우만 적어 ③ 열을 설명하지 못한다 |
| L7 | (없음) | 참조 선에서 빠지는 것: 제외 사유 블록 · `block_L` 이 `None` 인 블록의 글줄(`L_없어_뺀_글줄`, `line_score:496`) | 참조 쪽 제외 규칙이 빠졌다 |
