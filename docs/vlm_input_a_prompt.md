너는 포스터 이미지를 보고 «타이포 덩어리»(블록)의 영역을 좌표로 답한다. 결과는 JSON 파일 하나로 쓴다.

## 지켜야 할 것
- 목록에 적힌 이미지만 Read 도구로 연다. 그 밖의 파일·폴더는 열지도 찾지도(ls·grep·glob·find) 말라. 저장소 코드, JSON, 캐시, 문서 전부 금지다. 셸 명령도 쓰지 말라.
- 쓰기는 지정한 출력 파일 하나만 한다.
- 이미지는 그대로 본다. 확대·축소·자르기를 하지 않는다.
- 목록의 모든 장을 한다. 건너뛰지 않는다.

## 이미지에 있는 것
- 흰 바탕에 검은 글줄만 있다. 상자도 딱지도 그려져 있지 않다.
- 글의 내용은 읽지 않아도 된다.

## 판정 규칙 — 어느 줄들이 한 덩어리인가
- 줄들이 서로 붙어 있고, 그 무리 둘레에 훨씬 넓은 틈이 있으면 한 덩어리다. **안쪽 간격보다 두 배 넘게 벌어지는 자리에서 끊는다.**
- 틈만 본다. 틈을 px 로 재지 않고 이웃한 틈끼리 견준다.
- 크기는 보지 않는다. 줄마다 글자 크기가 달라도 붙어 있으면 한 덩어리다.
- 정렬도 보지 않는다. 다만 줄들이 가로로 전혀 안 겹치면 따로다 (단이 나뉜 경우).
- 줄이 하나뿐이어도 덩어리다.
- 애매하면 끊는다. 나중에 합칠 수는 있어도 쪼갤 수는 없다.
- 역할(제목·본문)은 따지지 않는다.

## 좌표
- 덩어리마다 **글자 잉크가 닿은 범위**를 감싸는 네모를 [x1, y1, x2, y2] 로 적는다.
- 값은 **0~1 로 정규화**한다 — x 는 이미지 너비로, y 는 이미지 높이로 나눈 값이다. 왼쪽 위가 (0, 0) 이다.
- 여백을 넉넉히 두지 말고 글자가 실제로 닿은 자리에 맞춘다.
- 소수 셋째 자리까지 적는다.

## 출력
지정한 경로에 아래 모양의 JSON 을 쓴다.

{"posters": [{"file": "<목록의 file 그대로>", "blocks": [[0.04, 0.02, 0.94, 0.09], [0.04, 0.12, 0.61, 0.18]], "notes": ""}, ...],
 "files_opened": ["<열어 본 파일 경로 전부>"],
 "model": "<네가 아는 네 모델 이름>",
 "notes": "<짧게. 판정이 어려웠던 장이 있으면>"}

마지막 보고에는 출력 파일 경로, 장별 덩어리 수, 열어 본 파일 목록만 적는다.
