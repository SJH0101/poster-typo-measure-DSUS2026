너는 포스터 이미지를 보고 글줄마다 «베이스라인» 의 y 좌표를 답한다. 결과는 JSON 파일 하나로 쓴다.

## 지켜야 할 것
- 목록에 적힌 이미지만 Read 도구로 연다. 그 밖의 파일·폴더는 열지도 찾지도(ls·grep·glob·find) 말라. 저장소 코드, JSON, 캐시, 문서 전부 금지다. 셸 명령도 쓰지 말라.
- 쓰기는 지정한 출력 파일 하나만 한다.
- 이미지는 그대로 본다. 확대·축소·자르기를 하지 않는다.
- 목록의 모든 장을 한다. 건너뛰지 않는다.

## 무엇을 답하나
- 포스터에 인쇄된 글줄을 눈에 보이는 대로 전부 찾는다. 사진·그림 속에 찍힌 글자는 뺀다.
- 한 글줄 = 같은 높이에 나란히 놓인 글자들의 한 줄. 좌우로 떨어진 두 단이 같은 높이에 있으면 따로 적는다.
- 글줄마다 세 값을 적는다.
  - `y` — 베이스라인: 글자들이 얹혀 있는 선 (x · n · H 같은 글자의 아래끝). g · p · y 같은 내림획은 무시한다.
  - `x1` · `x2` — 그 글줄 잉크의 왼끝 · 오른끝.
- 좌표는 **원본 이미지의 픽셀**이다. 왼쪽 위가 (0, 0). 목록에 각 장의 크기(너비 × 높이 px)가 있다. 정수로 적는다.
- 글의 내용은 적지 않아도 된다.

## 출력
지정한 경로에 아래 모양의 JSON 을 쓴다.

{"posters": [{"file": "<목록의 file 그대로>", "lines": [{"y": 212, "x1": 40, "x2": 380}, ...], "notes": ""}, ...],
 "files_opened": ["<열어 본 파일 경로 전부>"],
 "model": "<네가 아는 네 모델 이름>",
 "notes": "<짧게. 판정이 어려웠던 장이 있으면>"}

마지막 보고에는 출력 파일 경로, 장별 글줄 수, 열어 본 파일 목록만 적는다.
