너는 번호가 붙은 «줄 상자» 가 그려진 포스터 이미지를 보고, 번호마다 그 글줄의 «베이스라인» y 좌표를 답한다. 결과는 JSON 파일 하나로 쓴다.

## 지켜야 할 것
- 목록에 적힌 이미지만 Read 도구로 연다. 그 밖의 파일·폴더는 열지도 찾지도(ls·grep·glob·find) 말라. 저장소 코드, JSON, 캐시, 문서 전부 금지다. 셸 명령도 쓰지 말라.
- 쓰기는 지정한 출력 파일 하나만 한다.
- 이미지는 그대로 본다. 확대·축소·자르기를 하지 않는다.
- 목록의 모든 장, 모든 번호를 한다. 건너뛰지 않는다.

## 이미지에 있는 것
- 빨간 테두리 상자 하나가 글줄 하나다. 상자 왼쪽 위의 작은 딱지에 그 상자의 번호가 있다. 번호는 1 부터이고 목록에 장마다 번호 수가 적혀 있다.
- 상자 테두리는 글줄의 위치를 알려 주려고 그린 것이다. 상자의 아래 변은 베이스라인이 아니다 — 글자를 보고 답한다.

## 무엇을 답하나
- 번호마다 `y` — 베이스라인: 그 상자 안 글자들이 얹혀 있는 선 (x · n · H 같은 글자의 아래끝). g · p · y 같은 내림획은 무시한다.
- 좌표는 **목록에 적힌 이 이미지의 픽셀**이다 (이미지 크기는 목록에 있다). 왼쪽 위가 (0, 0). 정수로 적는다.
- 상자 안에 글자가 보이지 않으면 그 번호는 `null` 로 적는다.

## 출력
지정한 경로에 아래 모양의 JSON 을 쓴다.

{"posters": [{"file": "<목록의 file 그대로>", "baselines": [[1, 424], [2, 470], [3, null], ...], "notes": ""}, ...],
 "files_opened": ["<열어 본 파일 경로 전부>"],
 "model": "<네가 아는 네 모델 이름>",
 "notes": "<짧게. 판정이 어려웠던 장이 있으면>"}

마지막 보고에는 출력 파일 경로, 장별 답한 번호 수, 열어 본 파일 목록만 적는다.
